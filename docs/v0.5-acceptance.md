# v0.5 验收清单

- [x] `health_check()` 提供只读 SQLite/Redis 连接、schema、namespace、serializer 与 backend-specific 诊断；不会初始化 Redis keyspace 或 Consumer Group。
- [x] Redis 缺失配置 Consumer Group 会报 error；legacy JSON serializer identity 为兼容 warning；不可用 serializer 仍为 error，均有回归测试。
- [x] `check_consistency()` 覆盖 SQLite 审计表和 Redis ready/lease/delayed、DLQ/EQ、Stream、完整分页 PEL 不变量；PEL page size 可配置且 1000+ 尾部 stale/orphan 回归已覆盖。
- [x] `repair_consistency()` 默认 dry-run；实际 repair 边界已明确，无法安全修复的 PEL/lease 异常只诊断。
- [x] CLI 提供只读 consistency check；实际 repair 要求 `--apply --yes`。
- [x] SQLite 版本化迁移脚本、失败 rollback 与恢复测试。
- [x] Redis Consumer Group 升级、旧字段兼容读取和废弃 key 清理工具。
- [x] 完整 benchmark：reclaim、大 payload、高 dedup 冲突、多 consumer 并发，并记录容量建议。
- [x] Redis ACK/Lua 断连、SQLite 中断等故障注入测试，以及 Redis 不可用自动化测试。
- [x] Redis 集成测试以 `pytest.mark.redis` 标识；CI 显式执行该 marker，并且服务不可用会失败。
- [x] v0.1/v0.2/v0.3/v0.4 直升 v0.5 的汇总迁移与验证手册。
- [x] 包含 CHANGELOG、security policy、license、contribution guide 和 SemVer 声明。

发布验证：

```bash
uv sync --extra dev --extra redis --extra pydantic --locked
uv run ruff check src tests
uv run mypy src tests
uv run pytest --cov=taskqx -q
uv build
```
